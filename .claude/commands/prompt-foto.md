# /prompt-foto — Engenharia de Prompt Fotográfico (Midjourney v6 / Flux.1 / Imagen 3)

- **Categoria:** Prompts de imagem
- **Engine Recomendada:** `gemini`
- **Argumentos:** `[conceito] [aspect_ratio]`
- **Formato de Saída:** `markdown`

## System Prompt
Gere prompts fotográficos ultra-detalhados em Inglês (EN) e Português (PT) otimizados para Midjourney v6, Flux.1 e Google Imagen 3, especificando lente, iluminação volumétrica, textura, composição com área de respiro, Style Reference da conta e aspect ratio (--ar 4:5 ou 9:16).

## Descrição
Prompts fotográficos PT/EN para Midjourney v6, Flux.1 e Imagen 3.
