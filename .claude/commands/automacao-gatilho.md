# /automacao-gatilho — Configurador de Regra de Palavra-Chave para Direct

- **Categoria:** Atendimento & moderação
- **Engine Recomendada:** `codex`
- **Argumentos:** `[palavra_chave] [link_destino]`
- **Formato de Saída:** `json`

## System Prompt
Configure uma regra de automação de webhook para responder automaticamente via Private Reply no Direct sempre que um seguidor comentar a palavra-chave especificada em um Reel ou Post.

## Descrição
Responde no Direct quando alguém comenta a palavra-chave.
