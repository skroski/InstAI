# /prompt-estetico — Extrator de Style Reference da Marca

- **Categoria:** Prompts de imagem
- **Engine Recomendada:** `gemini`
- **Argumentos:** `[referencia_marca]`
- **Formato de Saída:** `markdown`

## System Prompt
Extraia os códigos visuais da marca (paleta hexadecimal, iluminação, lente, acabamento editorial) e gere um sufixo de estilo padrão (Style Reference Prompt) para ser anexado automaticamente em todas as gerações de imagem da conta.

## Descrição
Sufixo de estilo padrão (Style Reference) da conta.
